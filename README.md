# Jangira E Mitra — Smart Document Toolkit

A professional, browser-first document workspace for e-Mitra operators, cyber cafes, print shops, students and everyday document work.

## Product principle

**One Upload. Many Possibilities.**

The application maintains one Active Document workspace so users can move between crop, enhancement, PDF, ID-card, scanning, image and print workflows without repeatedly uploading the same source.

## Production modules

- Dashboard and Active Document workspace
- Multi-file image/PDF import
- PDF page workspace: select, reorder, rotate, duplicate, delete, extract and split
- Image enhancement and scan modes
- Advanced crop with manual four-point perspective correction
- Automatic document-corner detection
- ID card organizer with physical 85.60 × 53.98 mm sizing
- Multi-page camera scanner and scan queue
- Image conversion, resizing and compression
- Print Studio with physical paper presets and millimetre-based layout controls
- Recent-document metadata and browser-local workflow
- Responsive desktop and mobile workspace
- Undo/redo foundation and runtime diagnostics

## Privacy

Processing is designed to happen in the browser whenever possible. Files are not intentionally uploaded to a server by the core workflow.

## GitHub Pages

The repository is designed for static GitHub Pages hosting. External libraries are loaded only where required for PDF processing.

## Quality standard

A control is considered complete only when it performs its advertised operation. Visual placeholders and notification-only feature buttons are not considered production functionality.

## Roadmap

The remaining engineering work focuses on byte-level PDF manipulation, stronger document edge detection, complete scanner post-processing, batch ID-card pairing, exact physical print rendering, advanced image operations, worker-based performance optimization, accessibility, and systematic QA.
